Sobre o projeto

Este projeto é desenvolvido por alunos do curso de Análise e Desenvolvimento de Sistemas da Newton Paiva, como parte da disciplina ARA0062. O objetivo é criar uma aplicação web para a Padaria Triguinho, utilizando HTML, CSS, JavaScript e PHP. O intuito é fazer uma vitrine de produtos, permitindo que os clientes visualizem os itens disponíveis e entrem em contato com a padaria.
